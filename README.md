# Proskills

Proskills — интерактивный онлайн-курс по искусственному интеллекту с практическими заданиями, встроенной навигацией и тестами. Проект реализован на **React**, с адаптивной версткой и современным UI.

---

##  Ссылка на проект
[Proskills GitHub Repository](https://github.com/humblestudent123/Proskills)

---

##  Функционал

- Многостраничный курс с **разделами и модулями**.
- Интерактивная **навигация по темам** через sidebar.
- Возможность **перехода к тесту** после изучения материала.
- Адаптивный интерфейс для всех устройств (desktop, tablet, mobile).
- Модальные окна с дополнительной информацией.
- Карточки с теоретическим материалом и списки с примерами.
- Анимации при открытии модальных окон и секций.
- Поддержка **smooth scroll** к разделам курса.

---

##  Технологии

- **React 18** — создание SPA.
- **React Router v7** — маршрутизация.
- **CSS / SCSS** — оформление страниц и адаптивная верстка.
- **JavaScript (ES6+)** — логика и взаимодействие компонентов.
- Адаптивная верстка с использованием `flex` и `media queries`.

##  Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/humblestudent123/Proskills.git
cd Proskills
```

2. Установите зависимости:
npm install

3.Запустите локальный сервер разработки:
npm start
